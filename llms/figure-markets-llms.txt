# Figure Markets

> Figure Markets is a blockchain-native digital-asset marketplace built on the Provenance Blockchain that lets individuals and institutions trade, borrow against, and earn yield on crypto and real-world assets from a single account. The exchange runs on Connamara's EP3 matching engine (central limit order book) with FIX and REST APIs, spanning crypto, equities, bonds, alternative assets, and YLDS — the first SEC-registered yielding stablecoin. Backed by DCM Ventures.

## Products
- [Figure Exchange (Pro Trading)](https://www.figuremarkets.com/exchange/trade/): Central-limit-order-book trading for crypto and real-world assets.
- [Democratized Prime](https://www.figuremarkets.com/): HELOC-backed yield marketplace.
- [Crypto-Backed Loans](https://www.figuremarkets.com/): Borrow against crypto collateral at fixed rates.
- [YLDS](https://www.figuremarkets.com/): SEC-registered yielding stablecoin with daily interest accrual.

## API
- [Exchange API base](https://api.figuremarkets.com): Access-controlled trading API (markets, trading, account). Requires authentication; no public OpenAPI is currently published.
- Error envelope: RFC 9457 `application/problem+json`.
- Underlying technology: Connamara EP3 matching engine, FIX API, Provenance Blockchain settlement.
